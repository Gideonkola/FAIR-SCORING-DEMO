
# 📊 FAIR Scoring Tool

This is a simple Streamlit web application that demonstrates how FAIR (Findable, Accessible, Interoperable, Reusable) data scoring works using a rubric-based approach for a specific project.

## 🚀 Features

- Interactive checklist for FAIR criteria
- Real-time scoring for each FAIR principle:
  - Findable
  - Accessible
  - Interoperable
  - Reusable
- Total FAIR score calculation
- Simple and user-friendly interface
